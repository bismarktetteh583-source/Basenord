Reminders

The app can only notify while it is open or recently used, because it has no server. For reminders that always arrive, import the .ics file into your phone's calendar (Google/Apple Calendar): each ending date gets alarms at your chosen days.

A package ends on its last included day: a monthly package starting 1 Jan ends 31 Jan; a weekly one starting Monday ends Sunday. All data stays on this device.
